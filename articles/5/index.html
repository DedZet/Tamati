Документация Voltage

Поскольку вы пришли сюда, то наверняка, вы хотите изучить основы компьютерной графики и самостоятельно делать всё то, что делают крутые ребята. Самостоятельная работа - это чрезвычайно увлекательное и изобретательное занятие, которое поможет вам лучше понять графическое программирование. Однако есть несколько моментов, которые необходимо принять во внимание, прежде чем начать свое путешествие.

Предпосылки

Поскольку Voltage - это ещё не полноценный движок, то для работы с ним требуется язык программирования C++. Поэтому для работы с этим учебным пособием требуется хорошее знание языка программирования C++. Тем не менее, я попытаюсь объяснить большинство используемых концепций, включая продвинутые темы по C++, где это необходимо, поэтому не обязательно быть экспертом в C++, но вы должны уметь писать нечто большее, чем просто программу "Hello World". Если у вас нет большого опыта работы с C++, я могу порекомендовать бесплатное руководство по адресу www.learncpp.com

Также, мы будем использовать некоторую математику (линейную алгебру, геометрию и тригонометрию) по пути я постараюсь объяснить все необходимые математические понятия. Я не математик по натуре, поэтому, мои объяснения могут быть не совсем простыми для понимания. Не пугайтесь математических знаний, необходимых перед началом вашего знакомства с Voltage. Почти все концепции могут быть поняты с помощью базовых знаний. Я имею математическое образование, и я постараюсь свести математику к минимуму настолько, насколько это возможно. Большинство функций даже не требуют от вас понимания всей математики, если вы знаете, как её использовать.

Структура

Наша документация разделена на несколько общих разделов. Каждый раздел содержит несколько глав, в каждой из которых подробно объясняются различные концепции. Предметы преподаются линейно (поэтому рекомендуется начинать с начала и до конца, если не указано иное), где в каждой главе разъясняются основы теории и практические аспекты.

Синтаксис

В названии команд Voltage используется префикс vl и заглавные буквы для отделения слов, составляющих название команды. Подобным же образом Voltage определяет константы, начинающиеся с VL_ со всеми заглавными буквами и символом подчеркивания для отделения слов (например, GL_COLOR_BUFFER_BIT).

В библиотеке определено несколько версий некоторых команд, принимающих данные в различных форматах. К примеру, 3 в названии команды glColor3f() означает, что она получает три аргумента (существует и другая версия, получающая четыре аргумента). Буква f означает, что аргументы имеют формат числа с плавающей точкой (float). Подобное соглашение об именовании команд позволяет программисту использовать желаемый для него формат аргументов.

Некоторые команды воспринимают до восьми различных типов данных. Буквы, используемые в качестве суффиксов для указания конкретного типа данных в реализации Voltage для ISO - стандарта языка C++ приведены в таблице:

| Суффиксы | Тип данных                | Тип языка C++                  | Тип Voltage                |
| -------- | ------------------------- | ------------------------------ | -------------------------- |
| b        | целое 8 бит               | signed char                    | VLbyte                     |
| s        | целое 16 бит              | short                          | VLshort                    |
| i        | целое 32 бита             | int или long                   | VLint, VLsizei             |
| f        | дробь 32 бита             | float                          | VLfloat, VLclampf          |
| d        | дробь 64 бита             | double                         | VLdouble, Vlclampd         |
| ud       | беззнаковое целое 8 бит   | unsigned char                  | VLubyte, VLboolean         |
| us       | беззнаковое целое 16 бит  | unsigned short                 | VLushort                   |
| ui       | беззнаковое целое 32 бита | unsigned int или unsigned long | VLuint, VLenum, VLbitfield |

Некоторые команды последней буквой в своем имени могут иметь v, это означает, что команда принимает указатель на вектор (или массив) величин, а не несколько отдельных аргументов. Многие команды имеют и векторную, и не векторную версии, но среди тех, которые не попадают в это число, одни работают только с индивидуальными аргументами, в то время как другие в обязательном порядке требуют указатель на вектор величин в качестве части или всех своих аргументов.

vlColor3f(1.0,0.0,0.0);
VLfloat color_array[]={1.0,0.0,0.0};
vlColor3fv(color_array);

Кроме всего прочего, Voltage определяет тип VLvoid, который чаще всего применяется в векторных версиях команд. Звёздочка на конце означает, что приводимая информация относится ко всем версиям определенной команды: glColor*(). Если информация специфична только для подмножества версий одной команды, это будет отмечено при помощи добавления к вышеописанной записи части суффикса: glVertex*v() - означает все векторные версии команды установки вершины.

Машина состояний (State machine)

Voltage - это одна большая машина состояний. Многие переменные относятся к возможностям Voltage, которые можно включать или выключать командами vlEnable() или vlDisable().

Каждая переменная состояния имеет свое значение по умолчанию, и в любой момент вы можете опросить систему на предмет ее текущего значения. Обычно, чтобы это сделать, используется одна из следующих 6 команд: glGetBooleanv(), glGetDoublev(), glGetFloatv(), glGetIntegerv(), glGetPointerv(), glIsEnabled().

// создание обьекта
unsigned int objectId = 0;
vlGenObject(1, &objectId);

// привязываем обьект к контексту
vlBindObject(VL_WINDOW_TARGET, objectId);

// выставляем параметры для обьекта который был привязан к VL_WINDOW_TARGET
vlSetObjectOption(VL_WINDOW_TARGET, VL_OPTION_WINDOW_WIDTH, 800);
vlSetObjectOption(VL_WINDOW_TARGET, VL_OPTION_WINDOW_HEIGHT, 600);

// возвращаем значение контекстной цели по умолчанию
vlBindObject(VL_WINDOW_TARGET, 0);

Этот небольшой фрагмент кода представляет собой рабочий процесс, который вы будете часто видеть при работе с Voltage. Сначала мы создаем объект и сохраняем ссылку на него в качестве идентификатора (данные реального объекта хранятся за кулисами). Затем мы привязываем объект (используя его идентификатор) к target location of context (в примере оно определено как VL_WINDOW_TARGET). Затем мы устанавливаем параметры окна (ширина = 800, высота = 600). И наконец, снимаем привязку с объекта, установив текущий идентификатор объекта назначения окна равным 0.

Установленные нами параметры сохраняются в объекте, на который ссылается ObjectId, и восстанавливаются, как только мы привязываем объект обратно к VL_WINDOW_TARGET.

Самое замечательное в использовании этих объектов заключается в том, что мы можем определить более одного объекта в нашем приложении, задать их параметры, и всякий раз, когда мы запускаем операцию, использующую машину состояний, мы привязываем объект к нашим предпочтительным настройкам. Например, есть объекты, которые действуют как объекты-контейнеры для Данные 3D-модели (дом или персонаж), и всякий раз, когда мы хотим нарисовать один из них, мы привязываем объект, содержащий данные модели, которые мы хотим нарисовать (сначала мы создали и настроили параметры для этих объектов). Наличие нескольких объектов позволяет нам задавать множество моделей, и всякий раз, когда мы хотим нарисовать для конкретной модели мы просто привязываем соответствующий объект перед рисованием, не задавая все их параметры заново.

Куб

Теперь посмотрим, на что может быть похожа Voltage – программа. Следующий пример отображает белый квадрат на чёрном фоне.

#include <Voltage.h>

main()
{
	InitWindow();
	vlClearColor(0.0,0.0,0.0);
	vlClear(VL_COLOR_BUFFER_BIT);
	vlColor3f(1.0,1.0,1.0);
	vlOrtho(0.0,1.0,0.0,1.0,-1.0,1.0);
	vlBegin(VL_POLYGON);
	vlVertex3f(0.25,0.25,0.0);
	vlVertex3f(0.75,0.25,0.0);
	vlVertex3f(0.75,0.75,0.0);
	vlVertex3f(0.25,0.75,0.0);
	vlEnd();
	vlFlush();
	UpdateWindow()
}

InitWindow() - функция создания окна, обычно зависит от оконной системы, которую можно заменить (например на GLFW).

Уже две следующих строки являются командами Voltage: vlClearColor() задает цвет (в формате RGB), в который окно будет окрашиваться при его очистке. vlClear(VL_COLOR_BUFFER_BIT) очищает окно. После того, как очищающий цвет задан, окно всегда будет окрашиваться именно в него при вызовах vlClear(). Этот цвет может быть изменен повторным вызовом vlClearColor().

Похожим образом vlColor3f() задает цвет, который будет использоваться для рисования объектов (в данном случае белый). Начиная с этого момента, все объекты будут рисоваться белыми до тех пор, пока не последует замена этого цвета на другой.

vlOrtho() определяет координатную систему, на которую полагается движок при отрисовке финального изображения и проецировании изображения на экран.

vlBegin() и vlEnd() определяют объект, который следует нарисовать – в данном случае полигон с 4 вершинами.

Углы полигона определяются командами vlVertex3f(). Как можно догадаться по значениям аргументов, которые являются координатами (x, y, z), полигон представляет собой квадрат в плоскости z=0.

vlFlush() означает, что команды Voltage действительно выполнились, а не были сохранены в буфере в ожидании дальнейших команд.

UpdateWindow() - функция обновления кадров окна (тоже может быть заменена).
